# My Project (5) — The "Cube Surfer" Clone

> *"Пытался сделать игру как в тех самых рекламах мобильных игр 2023 года..."*

## 🤔 Что это?
Это мой учебный прототип на Unity, который я делал в июне 2023-го. За основу взята механика из популярной гиперказуалки **Cube Surfer!**. 

Суть проста: ты бежишь, собираешь желтые кубики, строишь из них башню, пытаешься не врезаться в красные кубы и не упасть в пропасть. Классика мобильного гейминга.

## 📉 Текущее состояние
Проект находится в состоянии **«Пока норм работает, но заниматься им я не стану»** (цитата из коммита от 13 июня). 
*   Визуал: уровень "Желтый куб на сером фоне".
*   Код: Немного поработал, кое-где сократил, вынес в отдельную функцию, объединил.
*   Статус: Заброшен на этапе прототипа, но история коммитов сохранена для истории.

## 📂 Что внутри?
*   `Assets` — тут вся магия (скрипты и сцены).
*   `ProjectSettings` — настройки проекта.
*   `Assembly-CSharp.csproj` — стандартные файлы сборки Unity.
*   `.gitignore` — чтобы не тащить в репозиторий тяжелые кэши `Library` и `Temp`.

## 🛠 Как посмотреть?(Надеюсь такого желания не будет)
1. Скачай проект.
2. Открой через Unity Hub (подойдет версия 2021/2022 LTS).
3. Запусти сцену и нажми Play.
4. Почувствуй себя в рекламе 2023 года.
